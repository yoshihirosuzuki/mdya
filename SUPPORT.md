# Getting support for mdya

mdya is maintained by one person on a best-effort basis. There is no formal SLA. Below covers how to get help, in order of preference.

## I think I found a bug

Open an issue using the **Bug report** template at <https://github.com/yoshihirosuzuki/mdya/issues/new?template=bug_report.yml>. The form prompts for the minimal repro context (mdya version, OS, what you tried, expected vs actual).

## I want to suggest a feature

Open an issue using the **Feature request** template at <https://github.com/yoshihirosuzuki/mdya/issues/new?template=feature_request.yml>. Please skim the [README](README.md) first — mdya is intentionally scoped to local-first search (no cloud LLM API, single binary distribution).

## I have a question or want to discuss something

Open a blank issue at <https://github.com/yoshihirosuzuki/mdya/issues/new>. GitHub Discussions are not currently enabled.

## I found a security vulnerability

**Do not open a public issue.** See [SECURITY.md](SECURITY.md) for the private reporting channels.
