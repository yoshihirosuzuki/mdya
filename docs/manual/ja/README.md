## 言葉

この説明書で使う言葉です。

- collection: 利用者が名前を付けて作り、文書を入れるもの。mdya の文書は、どれも、どれかの collection に入っています。
- collection タイプ: collection の文書の内容をどこから得るか。ディレクトリ、アーカイブ、raw の 3 つです ([collection と collection タイプ](collections.md))。
- 文書: 検索と取得の単位。ファイルとは限りません。文書のファイルタイプは、Markdown か PDF です。
- key: collection の中で文書を区別する名前。ディレクトリの collection では、ディレクトリからの相対パスです。
- 文書の本文: 文書の内容から取り出した、文書の文章の全体。Markdown では文書の内容そのもの、PDF では PDF から取り出した文字です。
- chunk: 文書の本文を区切ったもの。文書の本文の先頭から順に、0 から番号が付きます。
- 取り込み元: 文書の内容が来るところ。ディレクトリ、アーカイブのファイル、利用者が渡した文書の内容です。
- 取り込む: 取り込み元から文書を読み、検索できるようにすること。
- update: 取り込み元の今の中身を読み、collection の文書を、その中身に合わせること。
- インデックス: 検索のために mdya が持っているものの全体。
- 埋め込みモデル: 文章の意味を、検索に使える数値の列 (埋め込みベクトル) に表すモデル。ベクトル検索とハイブリッド検索に使います。
